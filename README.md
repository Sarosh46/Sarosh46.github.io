## Use of AI assistance
I used GitHub Copilot in Visual Studio Code to review the site, including its mobile layout, links and accessibility. I applied one of its suggestions, a smaller header padding on phone screens. Copilot also suggested a made-up LinkedIn address, which I rejected and replaced with my real profile link. I checked and tested every change before publishing.
